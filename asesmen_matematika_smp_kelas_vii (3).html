📊 Integrasi Otomatis Google Sheets & Excel Online

Ikuti 3 langkah mudah ini agar **nilai siswa otomatis masuk ke Google Sheet / Excel Online Anda** setiap kali siswa selesai mengerjakan kuis:

1. Buka Google Sheets Baru & Buka Apps Script:

Di Google Sheets Anda, klik menu Ekstensi (Extensions) ➔ Apps Script.

2. Hapus Kode Lama & Salin Kode Berikut:

function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // Buat header jika tabel masih kosong
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Tanggal & Waktu", "Nama Siswa", "Kelas", "Nilai (0-100)", "Jawaban Benar", "Durasi"]);
  }
  
  sheet.appendRow([
    new Date().toLocaleString('id-ID'),
    data.studentName,
    data.studentClass,
    data.score,
    data.correctCount + " / " + data.totalQuestions,
    data.durationText
  ]);
  
  return ContentService.createTextOutput("Success").setMimeType(ContentService.MimeType.TEXT);
}

3. Deploy sebagai Web App:

Klik Penerapan (Deploy) ➔ Penerapan Baru (New deployment). Pilih tipe Aplikasi Web (Web App), lalu ubah "Siapa yang memiliki akses" (Who has access) menjadi "Siapa Saja" (Anyone). Lalu klik Deploy dan salin URL Web App tersebut.
